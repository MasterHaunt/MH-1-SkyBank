# Приложение для анализа банковских транзакций

Выполнил: Чельтёмов Андрей Владимирович, поток PD 52/0

Функционал программы:
Загрузка банковских транзакций из файла `*.xlsx` с последующим анализом.

### Структура проекта:
Корневой каталог:
- Каталог "data" : файлы: operations.xlsx - исходный файл с информацией о транзакциях, test_operations.xlsx - файл для тестирования (40 транзакций за период 01.12.2021 - 31.12.2021)
- Каталог "logs" : файлы логов выполнения функций. Логи переписываются при каждом вызове функций;
- Каталог "reports" : файлы с отчётами в формате `*.xlsx`, сформированные программой;
- Каталог "src" : модули с реализацией функционала: 
- - utils.py - функции загрузки и преобразования в датафрейм информации из исходного файла, определения даты и времени последней транзакции, отбора транзакций за определённые периоды (текущий месяц, произвольный период), анализ транзакций, обращение к сайтам посредством API для получения курсов валют и стоимости акций;
- - views.py - функции вывода приветствия в зависимости от текущего времени суток, загрузки пользовательских настроек из файла "user_settings.json", запроса даты, на которую необходимо сформировать данные главной страницы, формирование данных главной страницы в формате json-строки;
- - services.py - функция отбора транзакций с номерами мобильных телефонов в описании за определённый период. Результат работы функции - Json-строка;
- - reports.py - функции расчёта среднего значения расходов по дням недели за три месяца, предшествующие указанной дате;
- Каталог "tests" : модули тестирование функций;
- Файл ".env" с переменными окружения (не включен в репозиторий);
- Файл ".env_template" - пример требуемого для работы содержания файла ".env";
- Файл "user_settings.json" - файл с настройками пользователя: наименования валют, курсы которых запрашиваются у сайта apilayer.com, наименования акций, стоимость которых запрашивается у сайта alphavantage.co;
- Файл ".gitignore" - настройки сохранения проекта в репозитории;
- Файл ".flake8" - настройки линтера Flake8;
- Файл "poetry.lock" - настройки зависимостей виртуального окружения (создан автоматически);
- Файл "pyproject.toml" - файл с информацией о пректе: основные сведения, зависимости, настройки линтеров;
- Модуль "config.py" - хранение констант (путей): корневой каталог, json-файл с настройками пользователя, excel-файл с информацией о транзакциях; 
- Модуль "main.py" - взаимодействие с пользователем: выбор функции, запрос даты / диапазона дат для анализа.
Реализованы следующие функции:
   - сумма расходов, сумма кэшбэка по каждой карте;
   - вывод информации о пяти наибольших по сумме транзакциях
   - вывод курсов валют, определённых в пользовательских настройках
   - вывод курсов акций, определённых в пользовательских настройках
